# 论文引用图谱

入口：打开本地论文 PDF → 左侧工具栏「参考文献」→ 面板标题栏的连接图按钮。再次点击返回参考文献卡片。图谱使用整个面板高度；不改变现有 PDF 链接预览、高亮或阅读位置。

- 默认显示当前论文的一跳引用关系：带圈圆点是当前论文，圆点是库内参考文献，方块是库内引用本文的论文，菱形是库外参考文献。
- 箭头从引用方指向被引用方；库内节点大小随本次图中的入边数量增加。互相引用的节点优先使用「本文引用」角色，两条方向边均保留。
- 悬停显示完整标题，单击库内节点用现有 `openGraphPath` 打开论文。库外节点用于展示；导入继续使用参考文献卡片的导入按钮。
- 顶栏提供当前论文／全库切换、刷新和适应视图。支持拖动节点、平移和缩放；初次布局结束自动适应画布。全库模式只显示参与库内引用关系的论文，不显示库外节点或孤立论文。
- 解析任务完成、论文导入、重命名和当前 sidecar 更新会刷新图谱。异步请求保留取消检查，切换论文后不显示旧请求的结果。读取失败通过 Toast 提示，可点击刷新重试。

`CitationGraphPanel` 恢复自删除提交 `433a9090a` 的前一版本，继续使用 `react-force-graph-2d`，按需加载绘图库；当前入口位于 `src/components/viewer/panels/references-panel.tsx`，图谱本身位于同目录的 `citation-graph-panel.tsx`。

数据来自本地 catalog 和已有 `source/agentero-cite.json`，通过 `paper_refs_graph` 读取。查询会按当前 catalog 在内存中补匹配新导入或移动的论文，不写回 sidecar，不发网络请求。缺失或不可读的 sidecar 不贡献引用边；只有当前论文时仍显示中心节点。

参考文献解析沿用现有 Semantic Scholar／Crossref 与本地 BibTeX／BBL 流程。打开论文或参考文献面板时的自动解析仍由现有 JobCenter 管理。图中的「引用本文」仅来自库内已解析论文；在线发现新引用论文仍使用独立的 `library_citing_scan`。此图不消费 Markdown 双链索引。

后端契约见 [API](../backend/api.md) 的 `paper_refs_graph`。
